# 成绩录入（网页版）

## 运行方式

双击打开 `index.html`，在浏览器中即可使用（推荐 Chrome/Edge）。

## 功能说明

- **摄像头拍照识别**：用手机或电脑摄像头拍摄实验报告，OCR 自动识别姓名和成绩
- **Tesseract.js**：纯前端 OCR（中文+英文），无需服务器，首次使用自动下载模型
- **学生名单导入**：导入 Excel 文件，程序自动识别学生姓名，用于姓名交叉验证
- **成绩录入**：识别后确认录入，自动记录到本地
- **导出 Excel**：一键导出已录入成绩为 CSV 文件

## 手机使用（推荐）

1. 用手机浏览器打开电脑上的网页（需同一局域网）
   - 方法：查看电脑 IP（如 `192.168.1.100`），手机浏览器访问 `http://192.168.1.100:8080/index.html`
   - 或者用 VS Code 的 Live Server 插件
2. 或直接将 `index.html` 上传到服务器

## 局域网部署（可选）

如需手机访问电脑上的网页，用任意静态服务器即可：

```bash
# Python 内置服务器（需先安装依赖）
pip install jszip
python -m http.server 8080
# 浏览器访问 http://localhost:8080/index.html
```
